# Documentation Archive

Historical session prompts, superseded handoffs, and one-shot review prompts
live here so `docs/plans/` stays limited to active contracts and executable
plans.

## Layout

| Path | Contents |
| --- | --- |
| `session-and-superseded/` | Agent/session prompts and handoffs replaced by later plans or the B6-G runbook |
| `reviews/` | One-shot review prompts that are not binding contracts |

## Rules

- Do **not** treat archived files as the current execution source of truth.
- Binding contracts remain under `docs/plans/` (especially
  `2026-07-21-b2-b7-technical-contracts.md` and the active B6-G runbook).
- Prefer adding a short note in a new plan over editing archived files in place.
