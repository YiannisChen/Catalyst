### Authoritative deep-immutability resolution (2026-08-21)

Pydantic `frozen=True` is shallow. M2 authoritative artifacts therefore do
not retain mutable list/dict fields after parsing:

- `CanonicalAsset.tickers` is a tuple and `subtype_metadata` is a canonical,
  key-sorted tuple of frozen `CanonicalMetadataEntry` records. Nested JSON
  objects and arrays are recursively stored as frozen typed objects/tuples;
  rich JSON input remains supported. Both Python and JSON serialization retain
  the authoritative mapping wire shape rather than exposing internal entries.
- `RetrievalHit.scores` and `ranks` accept the documented per-stage mapping
  input and store key-sorted frozen `StageScore`/`StageRank` tuples. Finite
  score and positive-rank validation lives on each immutable entry, preventing
  invalid post-parse injection. Serialization preserves the documented
  per-stage mapping wire shape.
- `CoverageSummary.content_state_counts` accepts the documented mapping input
  and stores unique, key-sorted frozen `ContentStateCount` entries while
  serializing to the documented mapping shape.
- Mapping inputs and JSON-array-like entry inputs are normalized to the same
  unique, key-sorted internal form; duplicate keys/stages fail closed.
  `CanonicalAsset`, `RetrievalHit`, `CoverageSummary`, and their immutable
  entry wrappers reject public `model_copy(update=...)`; copy-without-update
  remains available.
- `EvidenceState.upsert` rejects IDs already present in the opposite text/fact
  partition and rebuilds through full model validation. Public
  `model_copy(update=...)` is forbidden for the authoritative state; ordinary
  copy-without-update remains available.
- Public event `ArtifactRef` now requires schema version and valid SHA-256
  content hash. The outer event hides rejected nested input values while still
  failing strict event-type/payload validation; secret-bearing rejected
  failure payloads are never echoed.

Legacy/ordinary projection maps such as RunDTO manifest summaries and rerank
display changes are not authoritative identities and remain outside this
deep-immutability correction.
