# M5 — Semantic Cutover Implementation Plan (Amended 2026-08-27)

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** One EvidenceAnalyst → assessment → (one corrective round) → ClaimPlan → ClaimValidator → StreamingWriter → StructuralAssurance path produces valid results in 2 normal / 3 corrective logical model calls; the legacy MCJ semantic graph is removed from production only after the executable sealed-baseline comparison gate exits 0 and the supervisor approves.

**Tech Stack:** Python 3.11+, LangGraph, Pydantic v2 (`extra="forbid"`), LangChain provider clients with structured output + true streaming capability, pytest. Worktree-local `.venv`; four packages installed editable.

**Step 1: Write the failing test**
- `normalize_decision(decision, context_pack, capability_registry, policy_version) -> EvidenceAssessment` implements Final TSD §8.1 steps 1–8:
  1. extra=forbid; ≤3 hypotheses; unique refs present in pack inventory.
  2. Reject model-supplied runtime IDs/ceilings/recoverability/capability/limits/deadlines/batches as schema violations.
  3. Assign deterministic hypothesis/statement/mechanism/gap/relation IDs from persisted decision hash + stable ordinal + evidence refs.

  5.
