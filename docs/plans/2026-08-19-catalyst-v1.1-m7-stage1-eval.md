# M7 — Stage-1 Operational Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Run twelve hidden, human-reviewed cases through one manifest-bound V1.1 path with interpretable metrics (retrieval, attribution, trajectory), A1/A2/A3/A5 development signals, A4 readiness only, T4/user-smoke regression, and a reproducible Stage-1 report with no gold leakage.

**Tech Stack:** Python 3.11+, Pydantic v2, JSONL datasets, pytest, existing `packages/eval` harness/metrics, four-arm retrieval runner.
